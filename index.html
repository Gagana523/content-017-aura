#017 POST

FACEBOOK ACCOUNT
HACK METHODS

Cyber awareness post about common methods attackers may use to compromise online accounts. Learning about these attack techniques can help users recognize suspicious activity and improve account security.

⭕️ඔයාගේ Facebook Account එක හැක් වෙන්න පුළුවන් ක්‍රම 18 ක්⭕️

1. Social Engineering

Attackers manipulate users psychologically to gain sensitive information or access.

2. Facebook Phishing

Fake login pages designed to steal Facebook usernames and passwords.

3. Keylogging

Malicious software that records keyboard input including passwords.

4. Password Stealers

Programs created to extract saved credentials from devices or browsers.

5. Brute Force Attacks

Repeatedly trying password combinations until the correct one is found.

6. Dictionary Attacks

Using common password lists and dictionary words to guess passwords.

7. Exploiting Facebook's Trusted Friend Feature

Abusing account recovery systems and trusted contacts to gain access.

8. Fake SMS (To Hack Facebook Status)

Sending deceptive SMS messages pretending to be official notifications.

9. Session Hijacking

Stealing active session tokens to access accounts without passwords.

10. Sidejacking

Capturing session information over insecure wireless connections.

11. Clickjacking

Tricking users into clicking hidden malicious elements or links.

12. Mobile Phone Hacking

Compromising mobile devices to access apps, messages or credentials.

13. DNS Spoofing

Redirecting users to fake websites by altering DNS responses.

14. USB Hacking xD

Using infected USB devices to spread malware or steal data.

15. Man In the Middle Attacks

Intercepting communication between users and websites.

16. Botnets

Networks of infected devices controlled remotely for cyber attacks.

17. By Pass Security Question

Guessing or manipulating answers to security questions.

18. Cookies Grabing

Stealing browser cookies to hijack authenticated sessions.
